# Backyard Studio

Landing page de Backyard Studio en una sola página adaptable a escritorio, tablet y móvil.

## Estructura

```text
index.html
css/
  styles.css
js/
  main.js
  tailwind-config.js
assets/
  preview.png
```

La página presenta a Backyard Studio como un espacio de creación digital enfocado en producción audiovisual, dirección de arte, branding, estrategia de contenidos, Meta Ads, gestión de redes sociales y fotografía para redes.

La identidad visual usa la paleta de la referencia de Backyard Studio: carbón, azul intenso, magenta, amarillo, verde lima, violeta y blanco. El contraste y los acentos vivos refuerzan la idea de una página de marketing creativo. Los títulos usan Space Grotesk y los textos Inter para diferenciar la personalidad visual de la legibilidad. Las secciones y tarjetas aparecen con una animación suave al entrar en pantalla, desactivada automáticamente cuando el usuario prefiere reducir el movimiento. Tailwind CSS y Google Fonts se cargan desde CDN, por lo que se necesita conexión a internet al abrirla directamente en el navegador.
